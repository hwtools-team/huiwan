# 动效批量预览器

静态页面部署在 `https://hwtools-team.github.io/huiwan/motion-preview/`。文件只在浏览器本机解析和转换。

## 构建与检查

```sh
cd motion-preview
npm ci
npm run typecheck
npm test
npm run build
```

`src/App.tsx` 是界面与预览源代码，`src/lightweight-export.ts` 和 `src/raster-export.ts` 分别负责两种导出实现。构建更新 `app.js`，沿用已部署的 `app.css` 和 `theme-dark.css`。源码从原工具的最新线上对应工程恢复，后续应在此目录修改并重新构建，避免直接修改压缩产物。

## 导出选择

| 模式 | 行为 |
| --- | --- |
| 轻量 SVG | PNG 原图只存一次，完整仿射矩阵使用静态状态与离散透明度切换；保留原图、帧率、帧数和时长。支持旋转、斜切、镜像、非等比缩放。 |
| 3 MB SVG | 最终 UTF-8 文件最多 **3,000,000 字节**；先尝试原尺寸 PNG，再尝试 WebP 质量 92%、82%、72%，仍超限才降低内部渲染分辨率。保留透明背景、帧数、帧率、时长和外部画布尺寸。 |
| 高保真 SVG | 全帧 PNG，不设置文件字节上限。仍有浏览器像素安全限制。 |

轻量导出不处理可见矢量、裁剪、遮罩、动态替换及不能复用的图片；这些素材应使用逐帧模式。逐帧结果以当前 SVGA 播放器的预览效果为准，不能宣称支持播放器本身没有实现的源格式特性。WebP 模式需浏览器和接收端支持 SVG 内嵌 WebP；无法编码 WebP 时会报错，不会假装达标。页面显示实际字节大小、编码质量和内部渲染尺寸。

逐帧导出的初始画布受最长边 2048 和全片 6000 万像素限制。限体积模式的后续缩放最长边最低为 64 像素；仍无法达标会拒绝下载。转换在清空或移除时停止，最长 180 秒。所有帧共用离散时间轴，单帧素材保持常显。

## 验证范围

Node 回归测试覆盖矩阵、遮挡顺序、透明度、循环末帧、稀疏状态内存、预算降质/缩放/拒绝、取消及资源释放。编码器测试使用确定性替身，需要结合浏览器真实导出验收。

`tests/browser-harness.ts` 提供浏览器中的 `svgTest`：解析素材、转换、结构校验以及 SMIL 时间采样。将它用 esbuild 打包为浏览器 IIFE 后，放在本地 HTTP 测试页加载。`compare(video, svg, frames)` 对浏览器实际 SMIL opacity 状态进行静态化栅格对比；运行时将测试标签页置于前台，每次采样少量帧以免后台动画限速。该方法不替代 SVG 作为 `<img>` 的播放检查，也不代表其他浏览器或第三方接收端已验证。
